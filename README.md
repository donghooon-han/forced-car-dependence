# 버스가 없어서 차를 산다: '강제된 자동차 의존' 지역 진단

AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전(재단법인 숲과나눔·한겨레, 2026) 분석 코드입니다. 작성자: 한동훈

전국 229개 시·군·자치구에서 **소득은 낮은데 승용차 통근에 의존하고, 대중교통으로는 통근이 훨씬 오래 걸리는 지역**을 찾고, 그 의존이 굳어지는 추세와 대중교통 개선의 탄소 효과 조건을 분석합니다.

## 주요 결과

- 6가지 정의 중 5개 이상에서 반복 선정된 **핵심 17곳**: 동두천·포천·연천·가평·양주·여주(경기), 진천·음성·증평·옥천·영동(충북), 횡성·평창(강원), 칠곡·고령·영덕(경북), 금산(충남)
- 핵심 지역 승용차 통근 비율 62.2%(나머지 212곳 50.6%), 대중교통 7.8%(나머지 21.7%), 대중교통 이용자의 통근시간이 승용차 이용자보다 평균 16.8분 김(나머지 9.7분)
- 2015→2020 승용차 통근 비율 52.5%→62.2%(17곳 전체 9.7%p, 지역별 상승폭 중앙값 8.7%p), 17곳 모두 상승, 대중교통은 제자리
- 공급 검증(선정에 쓰지 않은 자료): 경기도 핵심 지역의 평일 평균 배차간격 중앙값 56.5분(나머지 40.9분, 2018), 배차간격과 승용차 통근 비율 순위상관 0.67\~0.76, 통근자 밀도 통제 편순위상관 0.37\~0.50
- 현장 확인: 진천군 농어촌버스 시간표(2025.11)에서 진천읍→산수산업단지 직행은 하루 4번(06:20·08:20·11:50·15:00)
- 탄소 시나리오(핵심 17곳, 버스 차량·km 2배, 증가율 = 2^탄력성 − 1): 승용차 통근자 3천\~9,600명 전환, 승용차 배출 연 3,700\~11,800 t 감소(승용차 쪽만 센 값). 현재 버스 차량·km 자료가 없어 '운행 2배'의 버스 배출은 계산하지 않고, 늘린 차량의 손익분기 재차인원(대형버스 4.2명, 원래 운전자 50%면 8.4명)을 따로 제시
- 랜덤포레스트(무작위 5겹 교차검증 R² 0.77, 시도 단위 0.49) + SHAP: 핵심 17곳에서 소득은 승용차 비율 예측값을 낮추는 쪽(−1.3%p)으로, 산업단지 통근·낮은 통근자 밀도·서울과의 거리·통근시간 격차는 높이는 쪽으로 기여(예측 기여도이며 인과 효과가 아님)
- 대형버스(약 723 gCO₂/km)는 원래 운전자가 평균 4.2명 이상 타야 승용차(173 gCO₂/인·km) 감소분과 같아짐. 새 승객 중 원래 운전자를 50%로 보면 늘린 버스의 평균 재차인원 8.4명이 손익분기(같은 이동거리, 빈 차 운행 제외 가정) → 최소 이동 서비스를 보장한 뒤 지역 여건에 맞는 수단(출퇴근 셔틀·소형 DRT·열차 연계)을 고름

### 배차간격 자료 만들기

`09_headway_validation.py`는 `data/raw/TS_경기_시군별_배차간격_2018_2019.json`이 있어야 실행됩니다. 이 파일이 없으면 이 단계만 건너뛰고 나머지는 그대로 실행됩니다.

1. [대중교통현황정보](https://www.kotsa.or.kr/ptc/inside_run.do)에서 대중교통 운행지표 → 배차간격(요일별)을 시/군/구 단위, 경기도로 조회합니다(2018년, 2019년).
2. 시군마다 `"시군명|연도": "시군명 월 화 수 목 금 토 일 강우 강설"` 형식으로 적어 JSON으로 저장합니다. 예: `"수원시|2019": "수원시 16.7 16.8 17.5 17.0 17.1 20.1 21.9 - -"`
3. 값이 없는 해는 `"NA"`로 적습니다.

## 실행

```bash
pip install -r requirements.txt
python run_all.py
```

`run_all.py`가 `02`~`10`번을 차례로 실행합니다(약 1~2분). 하나씩 돌리려면 `python code/02_analysis.py`처럼 번호 순서대로 실행하면 됩니다. 원자료 결합(`01`)부터 다시 하려면 행정동 경계 파일을 받은 뒤 `python run_all.py --with-01`을 실행하세요. 그림 글꼴은 맑은 고딕(Malgun Gothic)을 사용합니다.

## 주요 가정과 출처

- 승용차 173, 버스 55 gCO₂/인·km: 한국철도기술연구원(2010), 권영민·김수지·변지혜(2020, 한국ITS학회논문지 19(1)) 재인용
- 대형버스 약 723 gCO₂/km: 국립환경과학원 NIER-06 시험모드(서울시 환경분야 누리집)
- 버스 차량·km 탄력성 단기 0.38, 장기 0.66: Paulley 외(2006), Transport Policy 13(4), 표 4
- 새 승객 중 원래 운전자 비율 기준 50%·보수 30%: LA Metro(2016) Expo Line·Gold Line 연장 구간 신규 이용자 조사(44\~66%)를 참고한 가정(국내 실측값 아님)
- 승용차 평균 통근속도 30km/h, 연 250일 통근: 분석 가정(코드에서 변경 가능)

시군구 평균 자료이므로 개인 단위 결론을 내릴 수 없습니다. 2020년 조사는 코로나 시기이며, 버스 배차 등 공급 자료가 전국 단위로 없어 대중교통 수준을 실제 통근 행태로 측정했습니다. 버스정류장 자료는 버스정보시스템 연계 지자체만 온전하여 15개 시군을 결측 처리했습니다. 통근시간 격차는 같은 경로 비교가 아니라 수단별 이용자 평균의 차이이며, 철도역 자료는 2026년 기준이라 2020년 이후 개통 역(예: 연천, 2023.12)이 포함됩니다. 머신러닝 결과는 연관 관계이며 인과 효과가 아닙니다.
